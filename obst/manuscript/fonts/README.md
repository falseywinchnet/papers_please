# Dedication font

`NotoSansHebrew-Regular.ttf` is the static regular Noto Sans Hebrew font from
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansHebrew,
downloaded 2026-10-19. It is included unchanged. The repository's SIL Open
Font License is included as `OFL-NotoSansHebrew.txt`. This makes the Hebrew
dedication independent of the reader's installed operating-system fonts.

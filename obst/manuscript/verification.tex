\subsection{Implemented condensed constructors}\label{sec:legacy-19-5}
The compact path is now implemented in Python and independently in C++.
The product algorithm is the published compression, balanced core split,
staircase merge, and decompression method of~\cite{coremonge}. We credit
that primitive separately from the OBST reduction. A matrix stores its top
row, left column, and positive density triples. Two linear bucket passes
canonicalize the triples. Boundary extraction uses one-dimensional sweeps;
the product merge uses adjacent-entry recomputation along its staircase.
Each relevant core row or column is scanned only a constant number of times
per merge. None of these operations enumerates the full interval table.

\paragraph{Exact early stopping.}
The constructors compare consecutive completed layers by their top rows
and canonical core triples; the left column is fixed. Equality is therefore
equality of the whole table. A fixed point satisfies the ordinary OBST
recurrence with zero diagonal. Induction on interval length proves that
this recurrence has a unique solution, namely $C$. Stopping at such a fixed
point is exact. Equality of the single full-interval cost is not used.
Retained layer witnesses reconstruct a complete optimum: any unfinished
nonempty terminal would contribute at least $M>HW$, exceeding the
cost of an optimal tree of height at most $H$. All charges are nonnegative.
Reconstruction uses an explicit stack and visits every original key.

\paragraph{Implementation costs and arithmetic.}
Both implementations retain ordinary integer coordinate maps and recursive
witness nodes. Their witness storage is bounded by
$O(H(n+K)\log(n+1))$ words, where
$K=O(n+\min\{n^2,n\sqrt{WL}\})$ bounds the completed cores. This can
exceed the succinct storage bound in Theorem~1
by a logarithmic factor. Compression bounds recursive dimensions by core
size, and the core count halves along a recursive branch, so the time bound
is preserved. No succinct rank/select implementation is claimed.





The selected perturbation sweep certified amplitude 8 around 1,000 at
$n=256$, amplitude 4 at $n=512$, and amplitude 1 at $n=1,024$; larger tested
amplitudes at those sizes failed. These are seeded observations, not
universal thresholds. Ordinary random inputs failed the certificate.
Sizes 384, 768, and 1,000 deliberately skip the shortcut because their
minimum-$I$ shape space exceeds the logarithmic width budget.

\section{Weighted cluster tails and input sensitivity diagnostics}

\[
 D_xU_d(p)=U_d((t+1)p+e_x)-(t+1)U_d(p).

constructions reach 65,537 keys, with periods one, three, and five. At that
size the period-one construction examines exactly 131,073 root candidates;
the period-five case examines 655,325 phase candidates and 18 terminal
candidates. The candidate bounds and exact state count are checked against

Two further exact geometric constructions reach 4095 keys; their integers
grow with the input length, so their counts concern arithmetic work.

Every output is independently traversed to check key order, child links,
key and gap depths, and weighted cost. The eleven largest construction rows
have no separate quadratic optimality reference; their optimality guarantee
is Theorem~60. The result record retains the seed,
operation counts, exact costs, per-row reference scopes, and four source
hashes. No timing, fitted exponent, or infinite positive extension enters
